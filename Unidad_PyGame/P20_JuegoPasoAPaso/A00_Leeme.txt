Lo primero es preparar el entorno, necesitamos PyGame y PyOpenGL:

pip3 install PyGame
pip3 install PyOpenGL
pip3 install PyGame PyOpenGL PyOpenGL_accelerate
pip3 install mixer


Las versiones que se instalaron en su momento estan en el archivo 
requerimientos.txt y contiene:
